# Research Workbench — 已批准的业务 MVP

目标：Android、macOS、Windows 的本地离线科研工作台。用户已批准抽取通用思路另建应用，并要求先实现业务闭环，复杂故障场景低优先级。

本轮：研究目录/ZIP 显式导入 → 原始快照与真实 JSONL 条目 → Markdown/PDF 阅读与精读记录 → 有版本任务导出 → 绑定任务的结果导入与人工关联证据 → 主张/产物关联提纲 → Markdown 报告导出。

SQLite 保存科研元数据；应用私有目录保存不可覆盖的原始快照/附件。导入保留全部原始 JSON 字段，包括 unknown、needs_review、candidate；不把结构校验当科学认可。任务采用稳定 ID 与递增 revision，每次结果保留 run ID 和 task revision。包内命令仅展示，不执行。路径越界、符号链接及超限材料拒绝。文件可经显式启动的短期 LAN 单文件传输或人工交换；无后台同步和云依赖。

阅读包含可选择文本、Markdown 链接回跳、文献元数据、原文定位与独立笔记；PDF 阅读组件为 pdfrx（MIT，声明支持三目标平台），真正原生运行需各平台验收。批注是独立记录并绑定文档和位置，不修改 PDF 原字节。

界面：桌面侧栏/手机底部导航，概览、文库、任务、结果、写作。手机可编辑笔记和任务草案；运行计算任务是外部工具职责。

来源：借鉴本地优先、UUID、显式导入、恢复和证据来源等通用模式；未复制其他项目代码、schema 或工作文件。仓库仅发布新写的开发版源码与必要文档，不包含私有研究材料或安装包；导入研究材料时不运行论文代码。

后续：并发文本合并、断点续传、恰好一次执行、PDF 换版迁移、更多格式与引用样式、云检索/AI 可选适配。
